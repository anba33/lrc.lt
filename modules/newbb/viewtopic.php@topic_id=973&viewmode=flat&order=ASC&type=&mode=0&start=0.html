FIA07 Felbermayr (Porsche 996) - Kauno Grudai Sonex #1 ir #2
LM09 Risi Competizione (Ferrari) - Snoras #11 ir #20
LM07 Spyker Squadron (Spyker) - Snoras Spyker Squadron #85 ir #90

1. Automobilis, komanda
